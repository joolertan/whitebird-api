# Contributing

- Endpoints are described in `spec/services/*.yaml`; never edit generated code
  (`Code generated by whitebird-codegen. DO NOT EDIT.`). After changing the spec run
  `uv run python -m whitebird_codegen generate` in `tools/codegen`.
- `tools/wbscan` finds API changes: `npm run scan && node src/cli.ts diff`.
- Each SDK has its own checks; see the workflows in `.github/workflows/`.
- Docs: `bash scripts/docs-reference.sh && pip install -r docs/requirements.txt && mkdocs serve`.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org).
